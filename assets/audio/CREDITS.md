# Audio asset credits

The OGG effects in this folder were selected from **Sound effects Pack 2** by **phoenix1291** (also credited as SwissArcadeGameEntertainment).

- Source: <https://opengameart.org/content/sound-effects-pack-2>
- License: CC0, as listed on the source page. Attribution is optional; this note is kept with the project for provenance.
- The project includes the OGG variants from the `Blip`, `Explosions`, `Hit`, `Jump`, `Laser-weapon`, and `Power-up` groups. Files were renamed into the game's audio folders; no sounds were edited.

The manager picks a random variant and applies a small pitch shift so repeated events do not use the exact same clip every time.
